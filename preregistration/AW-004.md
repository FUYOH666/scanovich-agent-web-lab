## Phases

| Phase | Name | What it tests |
|------:|------|----------------|
| **0** | Surface verification | What URLs return under Accept / client conditions (`fetch.v1`) |
| **1** | Controlled representation comparison | Assigned variants A–D and their effect on exposure / labeled understanding |
| **2** | External agent observations | Product probes + organic Bring Your Agent runs (`run.v1` + `observation.v1`) |

Phase 0 does **not** claim A/B/C/D comparison. The 2026-08-08 snapshot is Phase 0 only.

**Phase 0 finding:** requesting Markdown (`Accept: text/markdown`) did not by itself produce Markdown on hub / AW-004 / BYA / Observatory — HTML was served. Artifact: `results/aw004_surfaces_2026-08-08T082742Z.json`.

## Hypothesis (directional; Phase 1+)

Different representations of the same commercial domain (HTML, HTML+JSON-LD, Markdown, Decision Packet) produce measurable differences in **exposure** and labeled **understanding** across agent families and crawlers. We do **not** preregister a ranking or SEO outcome.

## Scoring freeze (no post-hoc gold)

Do **not** invent gold labels after seeing model answers.

Required order:

```text
T0  freeze intents
 →  freeze scoring rubric (required_concepts, acceptable_variants,
        must_not_claim, required_sources, constraint_checks)
 →  freeze expected evidence shape
 →  HASH
 →  run models
 →  blind annotation
 →  score
```

Rubrics are sealed (`sealed/rubrics/`). Public shape: `schemas/scoring-rubric.schema.json`.  
A rubric is **not** a single “correct paragraph”; it is a checklist for blind scoring.

## Primary metric

**Phase 0:** `fetch` success and requested vs served representation.

**Phase 1–2** (labeled runs):

1. Exposure / fetch success by `variant` × `origin` × `environment.agent_family`
2. Labeled `understanding.entity` and mean capability/constraint scores when present

Secondary: citation presence; action occurrence (expected rare).

## Stopping condition (first scoring window)

Close when **any** of:

- ≥100 unique external agent fetches with attributable `origin`, **or**
- ≥30 independent human origins with paste-back, **or**
- 30 calendar days from 2026-08-08,

whichever comes first — then publish aggregate release-safe results and, when ready, unseal holdouts for hash verification.
