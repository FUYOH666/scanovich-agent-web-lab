# Limitations

## What this lab does not claim

- Guaranteed inclusion in ChatGPT (or any product) search summaries from allowing `OAI-SearchBot`
- Equivalence between manual product chats and search-index inclusion
- Ranking / SEO outcomes as primary success metrics
- That Observatory stubs are measured leaderboards before labeled data exists
- That Markdown is universally preferred by live user-facing agents

## Method limits

- Early observations may be sparse; absence of evidence is not evidence of absence.
- Product UIs change; record product/model version when known.
- Variant assignment on live probes is an experiment-side mechanism; clients may still request HTML.
- Public sample intents support reproducibility demos; validity scoring uses sealed holdouts.
- Organic releases are delayed by scrub/review — expect lag versus raw traffic.

## Contamination residual risk

Even with sealed holdouts, agents may retrieve live commercial pages, prior blog posts, or third-party mirrors. We report baskets and timestamps so readers can discount contaminated runs.

## Dual license

Code and documentation/datasets use different licenses (see README). Automatic license classifiers on GitHub may not detect multi-license layouts; the README section is authoritative.
